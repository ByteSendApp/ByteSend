## What Is a Contact Book?

A contact book is a mailing list. Each contact has an email address, optional name fields, a subscription status, and any number of custom properties you define.

Contact books are the foundation of ByteSend's marketing features. You need at least one contact book before you can:
- Send broadcast campaigns
- Use double opt-in confirmation flows
- Segment your audience for targeted sends

---

## Creating a Contact Book

### Via the dashboard

1. Go to [Contacts](https://bytesend.cloud/contacts)
2. Click **New Contact Book**
3. Give it a name (e.g. "Newsletter Subscribers", "Product Updates")
4. Optionally enable [Double Opt-In](/guides/double-opt-in)
5. Click **Create**

### Via the API

<Tip>
The examples assume a client set up as in the [Node.js](/get-started/nodejs), [Python](/get-started/python) or [Go](/get-started/go) guide. Every SDK reads `BYTESEND_API_KEY` from the environment.
</Tip>

<CodeGroup>

```ts Node.js
const { data: book, error } = await bytesend.contactBooks.create({
  name: "Newsletter Subscribers",
});

if (error) throw new Error(error.message);
console.log(book?.id); // keep this id for adding contacts
```

```python Python
book, _ = client.contact_books.create({"name": "Newsletter Subscribers"})
print(book["id"])  # keep this id for adding contacts
```

```go Go
book, err := client.ContactBooks.Create(ctx, bytesend.CreateContactBookPayload{
    Name: "Newsletter Subscribers",
})
if err != nil {
    log.Fatal(err)
}
fmt.Println(book.ID) // keep this id for adding contacts
```

```bash cURL
curl -X POST https://bytesend.cloud/api/v1/contactBooks \
  -H "Authorization: Bearer $BYTESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "Newsletter Subscribers"}'
```

</CodeGroup>

## Adding Contacts

Contacts can be added one at a time, in bulk, or imported from a CSV.

### Single contact

<CodeGroup>

```ts Node.js
await bytesend.contacts.create(contactBookId, {
  email: "jane@example.com",
  firstName: "Jane",
  lastName: "Smith",
});
```

```python Python
client.contacts.create(contact_book_id, {
    "email": "jane@example.com",
    "firstName": "Jane",
    "lastName": "Smith",
})
```

```go Go
_, err := client.Contacts.Create(ctx, contactBookID, bytesend.CreateContactPayload{
    Email:     "jane@example.com",
    FirstName: "Jane",
    LastName:  "Smith",
})
```

```bash cURL
curl -X POST https://bytesend.cloud/api/v1/contactBooks/{contactBookId}/contacts \
  -H "Authorization: Bearer $BYTESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"email": "jane@example.com", "firstName": "Jane", "lastName": "Smith"}'
```

</CodeGroup>

### Bulk import (API)

Use the bulk create endpoint to add up to 1,000 contacts in one request:

<CodeGroup>

```ts Node.js
await bytesend.contacts.bulkCreate(contactBookId, [
  { email: "alice@example.com", firstName: "Alice" },
  { email: "bob@example.com", firstName: "Bob" },
  { email: "carol@example.com", firstName: "Carol" },
]);
```

```python Python
client.contacts.bulk_create(contact_book_id, [
    {"email": "alice@example.com", "firstName": "Alice"},
    {"email": "bob@example.com", "firstName": "Bob"},
    {"email": "carol@example.com", "firstName": "Carol"},
])
```

```go Go
_, err := client.Contacts.BulkCreate(ctx, contactBookID, []bytesend.CreateContactPayload{
    {Email: "alice@example.com", FirstName: "Alice"},
    {Email: "bob@example.com", FirstName: "Bob"},
    {Email: "carol@example.com", FirstName: "Carol"},
})
```

```bash cURL
curl -X POST https://bytesend.cloud/api/v1/contactBooks/{contactBookId}/contacts/bulk \
  -H "Authorization: Bearer $BYTESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '[
    {"email": "alice@example.com", "firstName": "Alice"},
    {"email": "bob@example.com", "firstName": "Bob"},
    {"email": "carol@example.com", "firstName": "Carol"}
  ]'
```

</CodeGroup>

### CSV import (dashboard)

1. Go to your contact book → **Import**
2. Upload a CSV with columns: `email`, `firstName` (optional), `lastName` (optional)
3. Map CSV columns to contact fields
4. Click **Import**

## Contact Statuses

Every contact in a contact book has one of these statuses:

| Status | Description |
| ------ | ----------- |
| **Subscribed** | Active and will receive campaign emails |
| **Pending** | Added but awaiting double opt-in confirmation |
| **Unsubscribed** | Opted out, won't receive campaign emails |

<Warning>
Contacts with **Pending** or **Unsubscribed** status are excluded from campaign sends. They will not receive any marketing emails from ByteSend.
</Warning>

## Custom Properties

Beyond the standard `email`, `firstName`, and `lastName` fields, contacts support custom key-value properties for anything relevant to your audience: plan tier, signup source, account ID, etc.

<CodeGroup>

```ts Node.js
await bytesend.contacts.create(contactBookId, {
  email: "alice@example.com",
  firstName: "Alice",
  properties: {
    plan: "pro",
    signupSource: "landing-page",
    userId: "usr_abc123",
  },
});
```

```python Python
client.contacts.create(contact_book_id, {
    "email": "alice@example.com",
    "firstName": "Alice",
    "properties": {
        "plan": "pro",
        "signupSource": "landing-page",
        "userId": "usr_abc123",
    },
})
```

```go Go
_, err := client.Contacts.Create(ctx, contactBookID, bytesend.CreateContactPayload{
    Email:     "alice@example.com",
    FirstName: "Alice",
    Properties: map[string]string{
        "plan":         "pro",
        "signupSource": "landing-page",
        "userId":       "usr_abc123",
    },
})
```

```bash cURL
curl -X POST https://bytesend.cloud/api/v1/contactBooks/{contactBookId}/contacts \
  -H "Authorization: Bearer $BYTESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "alice@example.com",
    "firstName": "Alice",
    "properties": {"plan": "pro", "signupSource": "landing-page", "userId": "usr_abc123"}
  }'
```

</CodeGroup>

Custom properties can then be used in [campaign personalization](/guides/campaign-personalization) via `{{plan}}`, `{{signupSource}}`, etc.

## Upserting Contacts

Contacts are matched by email address within a contact book, so creating a contact that already exists updates their record instead of failing. Call it on every signup or profile change to keep the book in sync:

<CodeGroup>

```ts Node.js
await bytesend.contacts.create(contactBookId, {
  email: "alice@example.com",
  firstName: "Alice",
  properties: { plan: "pro" },
});
```

```python Python
client.contacts.create(contact_book_id, {
    "email": "alice@example.com",
    "firstName": "Alice",
    "properties": {"plan": "pro"},
})
```

```go Go
_, err := client.Contacts.Create(ctx, contactBookID, bytesend.CreateContactPayload{
    Email:      "alice@example.com",
    FirstName:  "Alice",
    Properties: map[string]string{"plan": "pro"},
})
```

```bash cURL
curl -X POST https://bytesend.cloud/api/v1/contactBooks/{contactBookId}/contacts \
  -H "Authorization: Bearer $BYTESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"email": "alice@example.com", "firstName": "Alice", "properties": {"plan": "pro"}}'
```

</CodeGroup>

## Unsubscribing Contacts

When a recipient unsubscribes, update their status immediately:

<CodeGroup>

```ts Node.js
await bytesend.contacts.update(contactBookId, contactId, {
  subscribed: false,
});
```

```python Python
client.contacts.update(contact_book_id, contact_id, {"subscribed": False})
```

```go Go
subscribed := false
_, err := client.Contacts.Update(ctx, contactBookID, contactID, bytesend.UpdateContactPayload{
    Subscribed: &subscribed,
})
```

```bash cURL
curl -X PATCH https://bytesend.cloud/api/v1/contactBooks/{contactBookId}/contacts/{contactId} \
  -H "Authorization: Bearer $BYTESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"subscribed": false}'
```

</CodeGroup>

If you handle unsubscribes via webhooks (e.g., reading from `email.complained`), do this automatically in your webhook handler so your list stays clean.
