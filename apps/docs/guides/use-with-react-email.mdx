## Introduction

[React Email](https://react.email/docs/introduction) is a library for building emails with React. In this guide, we will show you how to use ByteSend with React Email.

## Install dependencies

<CodeGroup>
  ```sh npm
  npm install bytesend-js @react-email/components react
  ```

```sh yarn
yarn add bytesend-js @react-email/components react
```

```sh pnpm
pnpm add bytesend-js @react-email/components react
```

```sh bun
bun add bytesend-js @react-email/components react
```

</CodeGroup>

## Create an email template

```tsx emails/welcome.tsx
import { Button, Html } from "@react-email/components";

export function WelcomeEmail({ url }: { url: string }) {
  return (
    <Html lang="en">
      <Button href={url}>Open dashboard</Button>
    </Html>
  );
}
```

## Send it with ByteSend

Pass the component as `react`. The SDK renders it to HTML for you, so there's no separate render step.

```tsx send.tsx
import { ByteSend } from "bytesend-js";
import { WelcomeEmail } from "./emails/welcome";

const bytesend = new ByteSend("bs_your_bytesend_api_key");

const { data, error } = await bytesend.emails.send({
  from: "Acme <hello@acme.com>",
  to: "customer@example.com",
  subject: "Welcome to Acme",
  react: <WelcomeEmail url="https://acme.com/dashboard" />,
});
```

<Note>
`react` isn't supported in `emails.batch()`. For batches, render each email with `render()` from `@react-email/components` and pass the result as `html`.
</Note>

## Run it

### TypeScript

Set `"jsx": "react-jsx"` in your `tsconfig.json`, then run the file with [`tsx`](https://tsx.is):

```json tsconfig.json
{
  "compilerOptions": { "jsx": "react-jsx" }
}
```

```sh
npx tsx send.tsx
```

See the complete [React Email TypeScript example](/get-started/examples#react-email-typescript).

### JavaScript

Use `.jsx` files and run them with `tsx`, which handles JSX without any Babel configuration:

```sh
npx tsx send.jsx
```

See the complete [React Email JavaScript example](/get-started/examples#react-email-javascript).
